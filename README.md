# NeoMundi Metrology Validation

Repository dedicated to the methodological consolidation, validation and reproducibility of NeoMundi measurements.

## Purpose

This repository is used to:

- define NeoMundi measurement units;
- document metrics and their limits;
- structure validation protocols;
- measure false positives and false negatives;
- compare NeoMundi with baselines;
- analyse repetitions and longitudinal drift;
- produce reproducible methodological evidence;
- record methodological decisions and authorized claims.

## Core principle

NeoMundi produces measured signals, not automatic verdicts.

## Methodological roadmap

1. Define
2. Label
3. Validate
4. Compare
5. Analyse longitudinally
6. Make reproducible
7. Replicate independently

## Current status

Initial methodological consolidation phase.
