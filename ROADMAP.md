# NeoMundi Metrology Validation Roadmap

## Phase 1 — Foundations

- [ ] Freeze the NeoMundi observation unit
- [ ] Document the corpus structure
- [ ] Create the claims and non-claims registry
- [ ] Create the executable metrics dictionary
- [ ] Separate factuality, coherence, compliance, stability and drift
- [ ] Define target events for each signal
- [ ] Define validation references and ground truth categories
- [ ] Document the limits and validity conditions of each metric

## Phase 2 — Validation Protocol

- [ ] Build positive and negative control sets
- [ ] Define the human review protocol
- [ ] Define annotation and arbitration rules
- [ ] Define TP, FP, TN and FN for each signal
- [ ] Separate calibration, validation and final test sets
- [ ] Freeze protocols, thresholds and success criteria before execution
- [ ] Define sampling levels

## Phase 3 — First Experimental Validation

- [ ] Select the first signal to validate
- [ ] Build the first labelled corpus
- [ ] Produce the first confusion matrix
- [ ] Measure precision, recall, specificity and F1
- [ ] Analyse false positives and false negatives
- [ ] Measure inter-rater agreement
- [ ] Adjust thresholds only on the calibration set

## Phase 4 — Comparative Value

- [ ] Define comparison baselines
- [ ] Compare NeoMundi with simple existing approaches
- [ ] Test NeoMundi alone
- [ ] Test baseline plus NeoMundi
- [ ] Measure incremental value
- [ ] Identify cases where NeoMundi does not improve performance

## Phase 5 — Repetitions and Longitudinal Analysis

- [ ] Analyse intra-prompt repetitions
- [ ] Study distributions, regimes and ruptures
- [ ] Freeze the longitudinal protocol
- [ ] Define noise, variation, rupture, trend, plateau and recovery
- [ ] Define drift confirmation thresholds
- [ ] Add a small quality-control set to each barometer

## Phase 6 — Reproducibility and Evidence

- [ ] Build the minimal reproducibility package
- [ ] Version corpora, metrics, thresholds, judges and results
- [ ] Define NeoMundi evidence levels
- [ ] Document the observation-to-action governance chain
- [ ] Create the methodological decision log
- [ ] Enable third-party replay and recalculation

## Phase 7 — Scientific Consolidation

- [ ] Replicate on another campaign
- [ ] Replicate across several models and risk families
- [ ] Replicate with another judge
- [ ] Run blind annotation or blind testing
- [ ] Organise an independent replication
- [ ] Publish limits, errors and non-results
- [ ] Test predictive claims separately
