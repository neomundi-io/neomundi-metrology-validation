# NeoMundi — Validation métrologique

Repository dédié à la consolidation méthodologique, à la validation et à la reproductibilité des mesures NeoMundi.

## Objectif

Ce repository est utilisé pour :

- définir les unités de mesure NeoMundi ;
- documenter les métriques et leurs limites ;
- structurer les protocoles de validation ;
- mesurer les faux positifs et les faux négatifs ;
- comparer NeoMundi à des baselines ;
- analyser les répétitions et les dérives longitudinales ;
- produire des preuves méthodologiques reproductibles ;
- tracer les décisions méthodologiques et les claims autorisés.

## Principe fondamental

NeoMundi produit des signaux mesurés, pas des verdicts automatiques.

## Roadmap méthodologique

1. Définir
2. Labelliser
3. Valider
4. Comparer
5. Analyser longitudinalement
6. Rendre reproductible
7. Faire répliquer indépendamment
